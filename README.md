# Smart School Pickup System – Mobile App (Ionic)

This repository contains the mobile application for the Smart School Pickup System.  
It includes two interfaces:
- **Parent App** — generates secure QR codes for student pickup  
- **Receptor App** — scans QR codes at the school entrance and initiates pickup requests  

Built with **Ionic**, **Angular**, and **Capacitor**.

---

## 🚀 Technologies
- Ionic Framework
- Angular
- Capacitor
- TypeScript
- Node.js & npm

---

## ⚙️ Requirements
Before running the project, ensure you have:

- **Node.js** (LTS recommended)
- **npm** package manager
- Ionic CLI installed globally:

## 📦 Build & Run
```
npm install -g @ionic/cli
npm install
ionic serve
```
Visit now -> http://localhost:8100
